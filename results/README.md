# Resultados de ejecución

`main` crea una carpeta nueva por ejecución y nunca usa resultados ficticios como sustitutos de OWID. Los archivos generados se excluyen del control de versiones para evitar confundir ejecuciones de distintas ediciones.

Conservar la carpeta completa y los originales de `data/` al preparar la entrega. `resumen.html` presenta resultados numéricos, interpretación y límites; los CSV contienen las tablas que deben alimentar el informe final.
